# Walaa Khalil Al-Adrah — Interior Design Portfolio

A luxury, editorial-style personal portfolio website for **Walaa Khalil Al-Adrah** (Interior Designer & 3D Visualizer based in Amman, Jordan).

Built with **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

## ✨ Features

- **Architectural & Editorial Design**: Inspired by luxury interior architecture publications with warm earthy tones (`#F7F3ED`, `#1B1714`, `#A68A62`).
- **Cinematic Animations**: Calm, elegant Framer Motion transitions and slow Ken-Burns hero image settling.
- **Selected Works Showcase**: Asymmetric editorial layout with case studies and detailed project pages (`/projects/[slug]`).
- **Tactile Materials Board**: Interactive showcase for Travertine, Fluted Oak, Limewash, and Aged Brass.
- **3D Visualization Section**: Photorealistic render studies with lighting physics and camera optics metadata.
- **Verified CV Information**: 3+ years experience across *Roza Outdoor Furniture*, *Al Manara Company*, and *Roya Design*, with academic degree from *Middle East University*.
- **Interactive Contact Form**: Inquiries form with direct contact channels (Amman, Jordan).
- **Responsive & Accessible**: Optimized for all viewports with accessible markup and fast static loading.

---

- **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Basil-Aladra/walaakhalilaladrah.git

# Navigate to the project directory
cd walaakhalilaladrah

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

### Building for Production
```bash
npm run build
npm run start
```
